# Semana 06 · Aplicaciones Compose

## Entregas

- `Lab06TecsupStore/`: carrito de compras TECSUP y práctica de interacción con productos. `mejora-ia` contiene la ampliación en la misma ruta.
- `evaluativa/SaludPlusPaciente/`: aplicación de citas para pacientes, con selección de especialidades, profesionales y horarios. Su versión ampliada se revisa en `mejora-ia`.

## Abrir

Abre la carpeta de la aplicación elegida en Android Studio. Revisa su README interno para detalles funcionales y límites de almacenamiento.
