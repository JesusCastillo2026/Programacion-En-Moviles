# TECSUP Store · Laboratorio de Semana 06

Aplicación Android de carrito de compras desarrollada con Kotlin y Jetpack Compose. Permite registrar productos y visualizar su información en una lista interactiva.

La rama `main` contiene la versión base; `mejora-ia` presenta la versión ampliada en la misma carpeta.

## Abrir

Abre esta carpeta en Android Studio y ejecuta el módulo `app`.
