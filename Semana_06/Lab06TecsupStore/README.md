# TECSUP Store · Laboratorio de Semana 06

Versión ampliada de la aplicación de carrito de compras, desarrollada con Kotlin y Jetpack Compose.

## Funciones destacadas

- Navegación entre Inicio, pedidos, favoritos y perfil.
- Registro de productos y validación de los datos ingresados.
- Gestión de favoritos con contador y prevención de duplicados.
- Búsqueda, categorías y listas de demostración.

Los datos de esta entrega se mantienen localmente en memoria. Abre esta carpeta en Android Studio y ejecuta el módulo `app`.
