# SaludPlus Citas — Semana 06

App Paciente construida tomando como referencia la clínica de la Semana 05 y los requisitos del laboratorio. El archivo `SaludPlusCitas.zip` mencionado en la guía no fue proporcionado; por ello, este proyecto reconstruye la estructura y las firmas necesarias desde cero.

- [SinIA/SaludPlusCitas](SinIA/SaludPlusCitas): versión base, con interfaz y lógica sencillas y sin comentarios dentro del código; está en `main`.
- [ConIA/SaludPlusCitasIA](https://github.com/JesusCastillo2026/Programacion-En-Moviles/tree/mejora-ia/Semana_06/evaluativa/ConIA/SaludPlusCitasIA): versión mejorada con calendario dinámico y documentación por bloques; está en `mejora-ia`, no en `main`.

Cada carpeta de proyecto se abre directamente en Android Studio. Los datos se mantienen en memoria y se reinician al cerrar la aplicación.
