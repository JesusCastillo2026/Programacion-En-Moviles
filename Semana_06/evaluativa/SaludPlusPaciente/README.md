# SaludPlus Paciente · Semana 06

Aplicación Android con Kotlin y Jetpack Compose para explorar especialidades y profesionales y completar un flujo de reserva de citas.

## Alcance

- Navegación entre las pantallas del flujo de citas.
- Selección de especialidad, profesional, fecha y horario.
- Datos de demostración gestionados por la aplicación.
- La rama `main` contiene la versión base y `mejora-ia` la versión ampliada en esta misma carpeta.

## Abrir

Abre esta carpeta en Android Studio, espera la sincronización de Gradle y ejecuta `app`. Consulta `PROMPTS.md` en `mejora-ia` para el registro de prompts de esa versión.
