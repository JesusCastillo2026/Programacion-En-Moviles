# SaludPlus Citas — versión base

App Paciente de Clínica SaludPlus para la Semana 06. Proyecto reconstruido desde la clínica de la Semana 05 porque no se recibió el ZIP del esqueleto citado en el PDF. Abre esta carpeta en Android Studio.

Incluye registro, inicio de sesión, especialidades, médicos, agendamiento, citas, perfil y los cuatro retos de la guía. No utiliza base de datos: toda la información se conserva en memoria durante la sesión.
