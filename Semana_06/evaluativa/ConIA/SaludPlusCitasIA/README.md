# SaludPlus Citas — ConIA

Proyecto Android independiente para la mejora de Clínica SaludPlus. Abre esta carpeta en Android Studio.

La versión amplía la base con un calendario de cinco días hábiles, navegación entre semanas, fecha en español, horarios reactivos y verificaciones de reglas. Las pantallas, el repositorio y los componentes están separados por responsabilidad. Los datos siguen en memoria; no se trata de un servicio médico real.

El proyecto se reconstruyó desde la clínica de la Semana 05 y la guía de Semana 06, porque no se recibió el ZIP `SaludPlusCitas.zip` citado por el docente.
