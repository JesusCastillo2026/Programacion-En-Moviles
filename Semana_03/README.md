# Semana 03 · Estado y formularios con Jetpack Compose

## Contenido

Registro de productos con validaciones y una tarea de registro de notas que practica controles interactivos, cálculo de promedios y presentación de resultados.

## Proyectos

- `Lab03RegistroProducto/`: laboratorio de registro de productos; la rama `mejora-ia` contiene su versión ampliada en esta misma ruta.
- `Tarea/RegistroNotasTarea/`: aplicación de la tarea de registro de notas.

## Abrir

Abre en Android Studio la carpeta del proyecto elegido, es decir, la que contiene `settings.gradle.kts`.
