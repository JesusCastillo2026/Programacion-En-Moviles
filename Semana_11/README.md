# Semana 11 · Autenticación y datos en Firebase

## Proyecto: Mis Cursos

`MisCursosJesusCastillo/` es una aplicación Android con Kotlin y Jetpack Compose para autenticación y gestión de cursos, integrada con Firebase Authentication y Cloud Firestore.

## Abrir y configurar

Abre la carpeta del proyecto en Android Studio. Para conectar tu propia instancia, coloca el archivo `google-services.json` proporcionado por Firebase dentro de `app/` y revisa las instrucciones del README interno y las reglas de Firestore antes de publicar cambios.
