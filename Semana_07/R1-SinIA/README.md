# GymTracker Pro - SinIA

Proyecto Android Kotlin + Jetpack Compose para el Laboratorio 07. El proyecto puede abrirse directamente desde esta carpeta en Android Studio.

## Incluye

- Room/SQLite local con las entidades `Usuario` y `Rutina`.
- Registro, inicio de sesión, menú principal con drawer y cierre de sesión.
- Crear, listar, editar y eliminar rutinas del usuario activo.
- Perfil con conteo de rutinas y volumen total calculado desde SQLite.
- Navegación Compose con `usuarioId` y `rutinaId` como argumentos.

Los datos permanecen en el dispositivo y funcionan sin conexión. Para abrir: Android Studio → Open → seleccionar esta carpeta.
