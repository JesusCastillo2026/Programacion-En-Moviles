# Semana 07 · Persistencia local con Room

## Proyecto: GymTracker Pro

`GymTrackerPro/` contiene la aplicación para registrar usuarios y administrar rutinas de ejercicio con operaciones CRUD y base de datos local Room.

La rama `main` contiene la versión base; `mejora-ia` amplía funciones e interfaz manteniendo la misma ruta del proyecto.

## Abrir en Android Studio

Abre `GymTrackerPro/`. Consulta el README interno para conocer funciones, persistencia y datos de demostración.
