# Prompt propuesto para mejorar la primera parte con IA

Utilizando Gemini, mejora una aplicacion Android hecha con Kotlin y Jetpack Compose para un laboratorio de navegacion. La version base tiene cuatro pantallas: inicio, lista de elementos, detalle con argumento entero y perfil. Quiero convertirla en una app mas elaborada tipo portal academico para estudiantes.

Requisitos:

- Mantener Jetpack Compose y Navigation Compose.
- Crear una pantalla de login demo.
- Agregar una pantalla de inicio con tarjetas informativas.
- Convertir la lista basica en un directorio de estudiantes con busqueda y filtros.
- Mantener una pantalla de detalle que reciba un `Int` desde la navegacion.
- Crear una pantalla de perfil editable con validacion de datos.
- Usar una paleta moderna, tarjetas limpias, buen espaciado y componentes reutilizables.
- Agregar documentacion breve en el codigo para explicar las decisiones importantes.
- Incluir pruebas unitarias para reglas de busqueda, validacion y rutas.
- No usar servicios reales ni almacenar contrasenas.
