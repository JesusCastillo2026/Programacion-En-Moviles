# Programación en Móviles

Repositorio académico de **Jesús Castillo Sumire** para el curso de Programación en Móviles de **TECSUP**. Reúne laboratorios, tareas y proyectos Android organizados por semana, con sus fuentes y guías para abrirlos en Android Studio.

## Navegación del repositorio

Cada entrega está dentro de `Semana_XX/`. Cuando un trabajo tiene dos versiones, ambas usan la misma ruta de proyecto en sus respectivas ramas:

- `main`: versión base del trabajo.
- `mejora-ia`: versión ampliada del mismo trabajo, cuando corresponde.

Así, al cambiar de rama se ve el proyecto de esa versión sin carpetas duplicadas `R1-SinIA` o `R2-ConIA`. Las tareas independientes permanecen en su propia carpeta, por ejemplo `Tarea` o `evaluativa`.

## Abrir un proyecto

1. Clona el repositorio y selecciona la rama que quieras revisar (`main` o `mejora-ia`).
2. Abre Android Studio y elige **Open**.
3. Selecciona la carpeta del proyecto indicada en el README de la semana; debe contener `settings.gradle` o `settings.gradle.kts`.
4. Espera la sincronización de Gradle y ejecuta la configuración `app` cuando el proyecto la incluya.

Cada aplicación conserva su configuración Gradle y sus recursos dentro de su propia carpeta. Algunas entregas usan datos de demostración locales; revisa el README del proyecto para conocer sus requisitos y alcance.
