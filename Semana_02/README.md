# Semana 02 · Fundamentos de Kotlin

## Contenido

Práctica de programación estructurada, colecciones, funciones y fundamentos de programación orientada a objetos mediante ejercicios de compras y boletas.

## Proyectos

- `CarritoCompras/`: aplicación del laboratorio con carrito, productos y cálculos.
- `Ejemplo_Boleta/`: proyecto complementario de boleta.

La rama `main` contiene la versión base de `CarritoCompras`; `mejora-ia` mantiene la versión ampliada en la misma ruta.

## Abrir

Abre la carpeta del proyecto que quieras revisar en Android Studio. El proyecto de boleta se abre desde `Ejemplo_Boleta/`.
