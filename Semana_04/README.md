# Semana 04 · Listas y formularios

## Contenido

Aplicación de formularios reactivos y listas en Jetpack Compose. El laboratorio trabaja el carrito TECSUP, la presentación de productos y el cálculo actualizado de subtotales, IGV y total.

## Proyecto

- `Lab04CarritoTecsup/`: proyecto Android del laboratorio.

## Abrir en Android Studio

Abre `Lab04CarritoTecsup/` con **Open** y espera la sincronización de Gradle.
